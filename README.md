# AMINASHAHID-07.3.1.006.2025-AND-RAMINALI-07.3.1.031.2025-.DPAM.MULTI.UTILITY.APP
Multi-utility Physics solver
Overview

This project is a Multi-Utility Application built using Python. It combines multiple useful tools into a single program, making it efficient and user-friendly.

Features: 
This application contains:
1. Calculator – A scientific calculator supporting basic arithmetic, trigonometric functions (sin, cos, tan), factorial, exponentiation, and DEG/RAD mode switching.
2. Temperature Converter – Converts between Celsius, Fahrenheit, and Kelvin with validation against absolute zero.
3. Unit Converter – Converts values across Length, Mass, Time, Speed, and Acceleration units.
4. Physics Solver – Solves common physics equations including Final Velocity, Displacement, Force, Kinetic Energy, and Work Done.
   
Built with:
Python 3

Run requirements: 
1. Python must be installed on your computer.
2. Download repository.
3. run.
